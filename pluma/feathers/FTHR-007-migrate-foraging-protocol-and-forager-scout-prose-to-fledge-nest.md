# FTHR-007: migrate foraging protocol and forager/scout prose to fledge nest

## Description
Close the loop: rewrite the workflow prose so foragers and scouts drive the new `fledge nest`
verbs instead of hand-assembling frontmatter and hand-deleting the nest. Edits the
agent-neutral source of truth under `internal/bootstrap/core/` and the Claude adapter source
under `internal/bootstrap/adapters/claude/`, reduces the now-duplicated scout-report template
to a pointer, updates the affected txtar fixtures, and regenerates this repo's own scaffolded
output. This feather is prose + fixtures only — no `internal/nest` or command logic changes.
Gated `oversight: merge` (user signs off on the diff before merge).

## Affected Modules
- **`internal/bootstrap/core/skills/fledge-orchestrate/foraging.md`** — the forager pipeline:
  step 3 ("delete existing … recreate") → `fledge nest scaffold`; the scout fan-out
  instruction → each scout runs `fledge nest scout --module <m>`; the "Frontmatter" blocks
  (forager + scout) → "frontmatter is written by `fledge nest …`; refresh with `fledge nest
  stamp`." Must stay harness-neutral (`TestCoreNeutral`, `registry_test.go`).
- **`internal/bootstrap/core/skills/fledge-orchestrate/templates/context-doc.md`** and
  **`templates/scout-report.md`** — the frontmatter YAML blocks become pointers at the CLI;
  `scout-report.md`'s body is now owned by `internal/nest` (FTHR-005), so this file is reduced
  to a short pointer noting the CLI emits it (kept for the section-order reference).
- **`internal/bootstrap/adapters/claude/agents/fledge-forager.md`** and
  **`fledge-context-scout.md`** — Claude-runtime specifics updated to call the verbs.
- **Fixtures** — `cmd/fledge/testdata/init.txtar`, `init_agents.txtar`, `agents.txtar` updated
  to the new embedded bytes; **this repo's** `.claude/agents/*` regenerated via `fledge init
  --refresh` (the source lives in `internal/bootstrap`; the repo copies are generated output
  per CLAUDE.md). See `.fledge/nest/architecture.md` → Layer 2 and "conventions.md →
  Agent-neutral core prose".

## Approach
- Rewrite `foraging.md`: replace the manual delete step with `fledge nest scaffold` (note it
  clears `raw/` too), and instruct scouts to create their report with `fledge nest scout
  --module <m>` then fill the sections. Replace both `### Frontmatter` blocks with one line
  each pointing at the CLI (create stamps it; `fledge nest stamp <file>` refreshes it). Keep
  the synthesis/index steps; the forager still writes doc *bodies*, now into CLI-created files
  (or stamps after editing).
- Reduce `templates/scout-report.md` and the `context-doc.md` frontmatter block to pointers;
  do not restate the YAML schema in prose (the binary owns it).
- Update the two Claude agent files' runtime-specifics bullets to name the verbs.
- Run `go test ./cmd/fledge -run TestScripts` and update the three txtar fixtures to the
  regenerated bytes; run `fledge init --refresh` and commit the regenerated `.claude/agents`
  changes in this repo.
